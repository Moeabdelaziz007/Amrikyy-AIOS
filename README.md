## 🌟 Overview

Amrikyy AI OS is a revolutionary web-based, simulated operating system designed to explore the future of human-computer interaction. It features a complete desktop experience, a sophisticated multi-agent AI system, real-time collaboration capabilities, and a comprehensive suite of creative and productivity tools—all orchestrated by Google's cutting-edge Gemini models.

This project represents a forward-looking concept that demonstrates how artificial intelligence can be deeply integrated into every layer of an operating system to create a truly proactive, personalized, and intelligent computing environment.

### 🎯 Key Highlights

- **100% Web-Based**: No installation required - runs entirely in your browser
- **AI-First Design**: Every feature is enhanced with Google Gemini AI
- **Multi-Agent System**: Specialized AI agents work together seamlessly
- **Real-Time Collaboration**: Work together with your team in real-time
- **Extensible Platform**: Create and deploy custom AI agents
- **Modern UI/UX**: Beautiful, responsive desktop environment with animated backgrounds

Before you begin, ensure you have the following installed:

- **Node.js** (v18 or higher) - [Download](https://nodejs.org/)
- **npm** (v9 or higher) - Comes with Node.js
- **Git** - [Download](https://git-scm.com/)
- **Google Gemini API Key** - [Get API Key](https://makersuite.google.com/app/apikey)

### Installation Steps

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Moeabdelaziz007/Amrikyy-AIOS.git
   cd Amrikyy-AIOS
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Set Up Environment Variables**
   
   Create a `.env.local` file in the root directory:
   ```bash
   cp .env.example .env.local
   ```
   
   Edit `.env.local` and add your API key:
   ```env
   VITE_API_KEY=your_google_gemini_api_key_here
   ```

4. **Run the Development Server**
   ```bash
   npm run dev
   ```

5. **Open in Browser**
   
   Navigate to `http://localhost:5173` (or the URL shown in terminal)

### First-Time User Guide

After launching Amrikyy AI OS:

1. **Explore the Desktop**: Familiarize yourself with the dock at the bottom
2. **Open App Launcher**: Click the grid icon to see all available apps
3. **Try Luna**: Start with the Luna travel agent for a guided AI experience
4. **Customize Dashboard**: Access Settings to choose your preferred dashboard layout
5. **Create an Agent**: Use Agent Forge to create your first custom AI agent
6. **Join Nexus**: Connect with the community in Nexus Chat

## 🚢 Deployment

### Deploy to Google Cloud Run

Full deployment instructions are available in [deployment-guide.md](deployment-guide.md).

**Quick Start:**

1. **Set GitHub Secrets**:
   - `GOOGLE_PROJECT_ID`
   - `GCP_SA_KEY`
   - `VITE_API_KEY`

2. **Push to Main Branch**:
   ```bash
   git push origin main
   ```

3. **GitHub Actions** will automatically build and deploy to Cloud Run

### Docker Deployment

Build and run with Docker:

```bash
# Build image
docker build --build-arg VITE_API_KEY=your_key -t amrikyy-aios .

# Run container
docker run -p 8080:8080 amrikyy-aios
```

### Manual Build

For static hosting (Netlify, Vercel, etc.):

```bash
npm run build
# Deploy contents of 'dist' folder
```

### Using the Gemini API

All AI features use Google's Gemini API. Example usage:


## 🐛 Troubleshooting

### Common Issues

#### Build Fails with ESLint Error

**Problem**: ESLint configuration file is corrupted
```bash
ESLint: SyntaxError: Invalid or unexpected token
```

**Solution**: 
```bash
# Recreate ESLint config
rm .eslintrc.cjs
npm run lint:fix
```

#### API Key Not Working

**Problem**: "Invalid API key" or 403 errors

**Solution**:
1. Verify your API key at [Google AI Studio](https://makersuite.google.com/)
2. Ensure `.env.local` uses `VITE_API_KEY=` prefix
3. Restart development server after changing env variables
4. Check API key has required permissions enabled

#### Port Already in Use

**Problem**: `Error: listen EADDRINUSE: address already in use :::5173`

**Solution**:
```bash
# Kill process on port 5173
lsof -ti:5173 | xargs kill -9

# Or use different port
npm run dev -- --port 3000
```

#### TypeScript Compilation Errors

**Problem**: Type errors during build

**Solution**:
```bash
# Clear cache and reinstall
rm -rf node_modules package-lock.json
npm install
npm run build
```

#### Images/Videos Not Generating

**Problem**: AI generation fails silently

**Solution**:
1. Check Developer Console for API quotas
2. Verify model availability in your region
3. Ensure API key has Imagen/Veo access enabled
4. Check browser console for detailed error messages
