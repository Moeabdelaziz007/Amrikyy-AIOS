## 🌟 نظرة عامة

Amrikyy AI OS هو نظام تشغيل ثوري محاكى وقائم على الويب مصمم لاستكشاف مستقبل التفاعل بين الإنسان والحاسوب. يتميز بتجربة سطح مكتب كاملة، ونظام ذكاء اصطناعي متعدد الوكلاء متطور، وقدرات تعاون في الوقت الفعلي، ومجموعة شاملة من الأدوات الإبداعية والإنتاجية - كل ذلك بتنسيق من نماذج Gemini المتطورة من Google.

يمثل هذا المشروع مفهومًا تطلعيًا يوضح كيف يمكن دمج الذكاء الاصطناعي بعمق في كل طبقة من طبقات نظام التشغيل لإنشاء بيئة حوسبة استباقية وشخصية وذكية حقًا.

### 🎯 أبرز الملامح

- **100٪ قائم على الويب**: لا يتطلب تثبيتًا - يعمل بالكامل في متصفحك
- **تصميم يعتمد على الذكاء الاصطناعي أولاً**: يتم تحسين كل ميزة باستخدام Google Gemini AI
- **نظام متعدد الوكلاء**: يعمل وكلاء الذكاء الاصطناعي المتخصصون معًا بسلاسة
- **تعاون في الوقت الفعلي**: اعمل مع فريقك في الوقت الفعلي
- **منصة قابلة للتوسيع**: قم بإنشاء ونشر وكلاء ذكاء اصطناعي مخصصين
- **واجهة مستخدم / تجربة مستخدم حديثة**: بيئة سطح مكتب جميلة وسريعة الاستجابة مع خلفيات متحركة

## ✨ الميزات الأساسية

### 🤖 نظام وكلاء الذكاء الاصطناعي

قلب Amrikyy AI OS هو بنيته المتطورة متعددة الوكلاء:

- **نظام متعدد الوكلاء**
  - وكلاء ذكاء اصطناعي متخصصون (Luna للسفر، فريق Marketing HQ، Atlas للمالية، إلخ.)
  - يتعاون الوكلاء ويشاركون المعرفة ويفوضون المهام بشكل مستقل
  - لكل وكيل مهارات وسمات شخصية فريدة

- **Agent Forge & Avatar Studio**
  - قم بإنشاء وكلاء ذكاء اصطناعي مخصصين بشخصيات شخصية
  - جهز الوكلاء بمهارات محددة من Skill Forge
  - صمم صورًا رمزية وملفات صوتية فريدة
  - انشر الوكلاء في سوق المجتمع

- **ناقل المعرفة المشترك (Chrono Vault)**
  - يخزن "محرك التفكير الكمي" المركزي التعلم الجماعي للوكلاء
  - يصبح النظام أكثر ذكاءً وإدراكًا للسياق تدريجيًا
  - ذاكرة ومشاركة المعرفة عبر الوكلاء

### 🎨 مجموعة إبداعية

أدوات إبداعية احترافية مدعومة بأحدث نماذج الذكاء الاصطناعي:

- **إنشاء الصور وتحريرها**
  - إنشاء صور من نص باستخدام Imagen 4 (`imagen-4.0-generate-001`)
  - قدرات تحرير متقدمة بمساعدة الذكاء الاصطناعي
  - إعدادات مسبقة لأنماط متعددة وخيارات تخصيص

- **Veo Video Studio**
  - إنشاء مقاطع فيديو عالية الجودة من نصوص أو صور
  - مدعوم بنموذج Veo من Google
  - "محسن المطالبات" المدمج بالذكاء الاصطناعي للحصول على أفضل النتائج
  - دعم تنسيقات ومدة الفيديو المختلفة

- **Audio Studio**
  - تحويل النص إلى كلام بنماذج صوتية متميزة
  - مجموعة واسعة من اللغات واللهجات وأنماط الصوت
  - تحكم دقيق في معلمات الكلام

- **Cognitive Canvas**
  - تحميل وتحليل المستندات (PDF، نص، صور)
  - تلخيص المحتوى المدعوم بالذكاء الاصطناعي
  - إنشاء مخططات مرئية تلقائيًا
  - تصور تفاعلي للبيانات

### 🚀 الإنتاجية وسير العمل

قم بتبسيط عملك باستخدام أدوات إنتاجية ذكية:

- **Creator Studio**
  - نظام شامل لإدارة المشاريع
  - تتبع وتنظيم المهام
  - مزامنة في الوقت الفعلي مع لوحات المعلومات
  - اقتراحات المهام وتحديد الأولويات المدعومة بالذكاء الاصطناعي

- **Workflow Studio**
  - مصمم سير عمل مرئي بواجهة سحب وإفلات
  - قدرات أتمتة متعددة الوكلاء
  - محرك "التنفيذ الذكي" المدعوم من Gemini
  - قوالب سير عمل مسبقة الإنشاء

- **مساحة عمل تعاونية**
  - تحرير الملاحظات التعاوني في الوقت الفعلي
  - لوحة بيضاء مشتركة للعصف الذهني المرئي
  - تشغيل الوسائط المتكامل (الموسيقى، يوتيوب)
  - دعم الاتصالات الصوتية والمرئية

- **Smart Watch**
  - ساعة عالمية مع دعم مناطق زمنية متعددة
  - مؤقت تركيز بأسلوب بومودورو
  - تتبع النشاط ورؤى الإنتاجية
  - إشعارات وتذكيرات قابلة للتخصيص

### 🛠️ أدوات المطورين والمستخدمين المتقدمين

أدوات متقدمة للمطورين والمستخدمين المتقدمين:

- **Developer Console**
  - واجهة إدارة مفاتيح API
  - تكوين ومراقبة الخدمة
  - سجلات وتصحيح الأخطاء في الوقت الفعلي

- **API Reference**
  - وثائق API شاملة داخل التطبيق
  - أمثلة تفاعلية ومقتطفات شفرة
  - تتبع الإصدار وسجل التغيير

- **Developer Toolkit**
  - ساحة لعب لاختبار مطالبات الذكاء الاصطناعي
  - واجهة ضبط `systemInstruction`
  - اختبار ومقارنة الاستجابات

- **Prompt Weaver**
  - أداة تسلسل المطالبات المرئية
  - إنشاء مهام سير عمل ذكاء اصطناعي متطورة متعددة الخطوات
  - مكتبة قوالب للأنماط الشائعة

- **Resource Hub**
  - مكتبة منسقة من الأدوات مفتوحة المصدر
  - أطر عمل ومكتبات الذكاء الاصطناعي / تعلم الآلة
  - موارد وأصول التصميم
  - مساهمات المجتمع والبرامج التعليمية

### 🌐 المحور الاجتماعي والاقتصادي

تواصل وشارك وحقق الدخل داخل النظام البيئي:

- **Gemini Store**
  - اكتشف وكلاء الذكاء الاصطناعي الذين أنشأهم المجتمع
  - تثبيت وتكوين بنقرة واحدة
  - مراجعات وتقييمات المستخدمين
  - وكلاء مميزون وشائعون

- **The Agora Marketplace**
  - سوق نظير إلى نظير لوكلاء الذكاء الاصطناعي وسير العمل
  - نظام معاملات باستخدام أرصدة الذكاء الاصطناعي
  - لوحة معلومات البائع والتحليلات
  - حماية المشتري وضمانات الجودة

- **Nexus Live Chat**
  - دردشة في الوقت الفعلي على مستوى النظام
  - قنوات عامة ورسائل خاصة
  - دعم الوسائط الغنية (صور، ملفات، روابط)
  - إرشادات مجتمعية معتدلة بالذكاء الاصطناعي

### 📈 النمو وتحقيق الدخل

إشراك المستخدمين والمبدعين من خلال الألعاب:

## 📱 دليل التطبيقات والميزات الكامل

يتضمن Amrikyy AI OS **أكثر من 50 تطبيقًا متكاملاً** عبر فئات مختلفة. إليك دليل شامل لكل تطبيق وكيفية استخدامه:

### 🤖 وكلاء الذكاء الاصطناعي (مساعدون متخصصون)

#### **Luna - وكيل تخطيط السفر**
- **الغرض**: مساعد خبير في تخطيط السفر بالذكاء الاصطناعي
- **كيفية الاستخدام**:
  - انقر على أيقونة Luna في الشريط أو مشغل التطبيقات
  - اطلب توصيات الوجهات أو مسارات الرحلات أو نصائح السفر
  - تحلل Luna الرحلات الجوية والفنادق والأنشطة باستخدام خرائط Google وبحث الرحلات الجوية
- **الميزات الرئيسية**: إنشاء مسار رحلة متعدد الأيام، تخطيط الميزانية، تحديثات السفر في الوقت الفعلي

#### **Karim - وكيل تحسين الميزانية**
- **الغرض**: التخطيط المالي وتحسين التكلفة
- **كيفية الاستخدام**:
  - افتح Karim من قائمة الوكلاء
  - اطلب تحليل الميزانية أو توصيات توفير التكاليف
  - يعمل بالتعاون مع Luna لميزانيات السفر
- **الميزات الرئيسية**: تخصيص ذكي للميزانية، إيجاد الصفقات، تتبع النفقات

#### **Scout - وكيل إيجاد الصفقات**
- **الغرض**: يفحص آلاف المصادر للحصول على أفضل الصفقات
- **كيفية الاستخدام**:
  - قم بتنشيط Scout للبحث عن منتجات أو خدمات محددة
  - يتلقى إشعارات استباقية حول انخفاض الأسعار
  - يتكامل مع مهام سير عمل السفر والتسوق
- **الميزات الرئيسية**: مقارنة الأسعار، تنبيهات الصفقات، تتبع الأسعار التاريخية

#### **Maya - وكيل دعم العملاء**
- **الغرض**: خدمة عملاء ذكية وحل المشكلات
- **كيفية الاستخدام**:
  - تحدث مع Maya للمساعدة في الحجوزات أو الخدمات
  - دعم ممكّن صوتيًا مع تحويل النص إلى كلام
  - يتعامل مع الاستفسارات بتعاطف وكفاءة
- **الميزات الرئيسية**: توفر على مدار الساعة طوال أيام الأسبوع، دعم متعدد اللغات، تحليل المشاعر

#### **Jules - وكيل تصحيح أخطاء النظام والشفاء الذاتي**
- **الغرض**: تشخيص النظام وحل المشكلات تلقائيًا
- **كيفية الاستخدام**:
  - يعمل تلقائيًا في الخلفية
  - عرض التشخيصات في سجل الأحداث
  - تشغيل فحوصات سلامة النظام يدويًا
- **الميزات الرئيسية**: تصحيح الأخطاء التلقائي، تحسين الأداء، تسجيل الأخطاء

#### **Atlas - استراتيجي الأعمال والمالية**
- **الغرض**: تحليلات الأعمال والتخطيط المالي
- **كيفية الاستخدام**:
  - افتح تطبيق Atlas Finance للحصول على لوحات معلومات شاملة
  - اطلب تقارير مالية أو تحليل السوق أو التوقعات
  - تتبع الاستثمارات ومقاييس الأعمال
- **الميزات الرئيسية**: بيانات السوق في الوقت الفعلي، إدارة المحافظ، التحليلات التنبؤية

#### **Cortex - وكيل التفكير التعاوني**
- **الغرض**: عصف ذهني جماعي وتفكير إبداعي
- **كيفية الاستخدام**:
  - ابدأ جلسات التفكير في تطبيق Workspace
  - يجمع Cortex مدخلات الفريق ويقترح الروابط
  - يتكامل مع YouTube للبحث
- **الميزات الرئيسية**: تجميع الأفكار، تحليل الاتجاهات، المطالبات الإبداعية

#### **وكلاء فريق التسويق (Orion, Helios, Leo, Zara, Rex, Clio)**
- **الغرض**: أتمتة قسم التسويق بالكامل
- **كيفية الاستخدام**:
  - الوصول عبر تطبيق Marketing HQ
  - يتخصص كل وكيل (المحتوى، تحسين محركات البحث، وسائل التواصل الاجتماعي، التحليلات، التصميم، كتابة النصوص)
  - التعاون في الحملات وإنشاء المحتوى
- **الميزات الرئيسية**: تخطيط الحملات، إنشاء المحتوى، تتبع الأداء

### 🎨 تطبيقات إبداعية ووسائط

#### **مولد الصور (Imagen 4)**
- **الغرض**: إنشاء الصور وتحريرها بالذكاء الاصطناعي
- **كيفية الاستخدام**:
  1. افتح مولد الصور من الشريط
  2. أدخل مطالبة نصية تصف الصورة التي تريدها
  3. اضبط الإعدادات (النمط، نسبة العرض إلى الارتفاع، الجودة)
  4. انقر فوق "إنشاء" وانتظر حتى يقوم Imagen 4 بإنشاء صورتك
  5. قم بتنزيل النتيجة أو تحريرها
- **الميزات الرئيسية**: نص إلى صورة، نقل النمط، تحرير الصور، إنشاء دفعة

#### **Veo Video Studio**
- **الغرض**: إنشاء فيديو احترافي بالذكاء الاصطناعي
- **كيفية الاستخدام**:
  1. قم بتشغيل Veo Video Studio
  2. اختر نوع الإدخال (مطالبة نصية أو صورة أساسية)
  3. استخدم محسن المطالبات بالذكاء الاصطناعي للحصول على نتائج أفضل
  4. اضبط مدة الفيديو ومعلمات الجودة
  5. قم بإنشاء ومعاينة الفيديو الخاص بك
- **الميزات الرئيسية**: نص إلى فيديو، صورة إلى فيديو، تحسين المطالبات، إخراج عالي الدقة

#### **Audio Studio**
- **الغرض**: تحويل النص إلى كلام وإنشاء الصوت
- **كيفية الاستخدام**:
  1. افتح Audio Studio
  2. اكتب أو الصق النص الخاص بك
  3. حدد الصوت واللغة واللهجة
  4. اضبط السرعة والنبرة والنغمة
  5. قم بإنشاء وتنزيل الصوت
- **الميزات الرئيسية**: أكثر من 30 صوتًا متميزًا، متعدد اللغات، التحكم في النغمة العاطفية، دعم SSML

#### **Cognitive Canvas**
- **الغرض**: تحليل المستندات وتصورها
- **كيفية الاستخدام**:
  1. قم بتحميل المستندات (PDF، TXT، صور)
  2. يحلل الذكاء الاصطناعي المحتوى ويستخرج المعلومات الأساسية

## 🚀 البدء

### المتطلبات الأساسية

قبل أن تبدأ، تأكد من تثبيت ما يلي:

- **Node.js** (v18 أو أعلى) - [تنزيل](https://nodejs.org/)
- **npm** (v9 أو أعلى) - يأتي مع Node.js
- **Git** - [تنزيل](https://git-scm.com/)
- **مفتاح Google Gemini API** - [الحصول على مفتاح API](https://makersuite.google.com/app/apikey)

### خطوات التثبيت

1. **استنساخ المستودع**
   ```bash
   git clone https://github.com/Moeabdelaziz007/Amrikyy-AIOS.git
   cd Amrikyy-AIOS
   ```

2. **تثبيت التبعيات**
   ```bash
   npm install
   ```

3. **إعداد متغيرات البيئة**

   قم بإنشاء ملف `.env.local` في الدليل الجذر:
   ```bash
   cp .env.example .env.local
   ```

   قم بتحرير `.env.local` وأضف مفتاح API الخاص بك:
   ```env
   VITE_API_KEY=your_google_gemini_api_key_here
   ```

4. **تشغيل خادم التطوير**
   ```bash
   npm run dev
   ```

5. **الفتح في المتصفح**

   انتقل إلى `http://localhost:5173` (أو عنوان URL الموضح في المحطة الطرفية)

### دليل المستخدم لأول مرة

بعد تشغيل Amrikyy AI OS:

1. **استكشف سطح المكتب**: تعرف على الشريط في الأسفل

5. **إنشاء وكيل**: استخدم Agent Forge لإنشاء أول وكيل ذكاء اصطناعي مخصص لك

## 🐛 استكشاف الأخطاء وإصلاحها

### المشكلات الشائعة

#### فشل البناء مع خطأ ESLint

**المشكلة**: ملف تكوين ESLint تالف
```bash
ESLint: SyntaxError: Invalid or unexpected token
```

**الحل**:
```bash
# إعادة إنشاء تكوين ESLint
rm .eslintrc.cjs
npm run lint:fix
```

#### مفتاح API لا يعمل

**المشكلة**: "مفتاح API غير صالح" أو أخطاء 403

**الحل**:
1. تحقق من مفتاح API الخاص بك في [Google AI Studio](https://makersuite.google.com/)
2. تأكد من أن `.env.local` يستخدم بادئة `VITE_API_KEY=`
3. أعد تشغيل خادم التطوير بعد تغيير متغيرات البيئة
4. تحقق من أن مفتاح API لديه الأذونات المطلوبة ممكّنة

#### المنفذ قيد الاستخدام بالفعل

**المشكلة**: `Error: listen EADDRINUSE: address already in use :::5173`

**الحل**:
```bash
# قتل العملية على المنفذ 5173
lsof -ti:5173 | xargs kill -9

# أو استخدم منفذًا مختلفًا
npm run dev -- --port 3000
```

#### أخطاء تجميع TypeScript

**المشكلة**: أخطاء النوع أثناء البناء

**الحل**:
```bash
# مسح ذاكرة التخزين المؤقت وإعادة التثبيت
rm -rf node_modules package-lock.json
npm install
npm run build
```

#### عدم إنشاء الصور / مقاطع الفيديو

**المشكلة**: فشل إنشاء الذكاء الاصطناعي بصمت

**الحل**:
1. تحقق من Developer Console لمعرفة حصص API
2. تحقق من توفر النموذج في منطقتك
3. تأكد من تمكين الوصول إلى Imagen / Veo لمفتاح API
4. تحقق من وحدة تحكم المتصفح للحصول على رسائل خطأ مفصلة
