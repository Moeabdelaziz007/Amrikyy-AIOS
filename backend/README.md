# Amrikyy AI OS Backend

This backend provides API endpoints for the Amrikyy AI OS frontend including AI endpoints and integration proxies.

## Prerequisites
- Node 18+
- npm
- A Google Cloud API key with access to Speech-to-Text and Text-to-Speech (recommended to use a service account / server key)
- Google OAuth client credentials for Gmail/Calendar integration

## Important environment variables
Set these in `backend/.env` (or in your environment):

```
PORT=5000
GOOGLE_API_KEY=your_google_api_key_here
GOOGLE_CLIENT_ID=your_google_oauth_client_id
GOOGLE_CLIENT_SECRET=your_google_oauth_client_secret
GOOGLE_REDIRECT_URI=http://localhost:5000/api/gmail/callback
NODE_ENV=development
```

## Run locally
```bash
cd backend
npm install
npm run dev
```

## Endpoints
- `/api/speech/transcribe` - POST multipart/form-data { audio: file } -> returns { transcript }
- `/api/speech/synthesize` - POST JSON { text } -> returns { audioContent: base64 }
- `/api/ai/travel-plan` - POST JSON travel request -> returns structured itinerary JSON (generated by Gemini)
- `/api/agents/:id/reason` - POST JSON { prompt, context? } -> returns quantum-enhanced reasoning trace, hypotheses, and confidence

### Quantum Reasoning Endpoint
**POST** `/api/agents/:id/reason`

**Request Body:**
```json
{
  "prompt": "string",
  "context": ["string", ...] // optional
}
```

**Response:**
```json
{
  "content": "string", // main response
  "confidence": number,
  "reasoning_trace": [
    {
      "step_number": number,
      "step_type": "string",
      "description": "string",
      "timestamp": "ISO8601 string"
    }
  ],
  "quantum_metadata": {
    "model_used": "string",
    "exploration_depth": number,
    "validation_method": "string",
    "processing_time": number,
    "topology_score": number
  },
  "hypotheses": [
    {
      "id": "string",
      "title": "string",
      "description": "string",
      "confidence": number,
      "reasoning": "string",
      "evidence": ["string", ...]
    }
  ]
}
```

## Notes
- For production, keep `GOOGLE_API_KEY` only on the server (do not commit it).
- The speech endpoints validate file size and mime type.
- The travel planner route generates JSON via the AI service; parsing is best-effort.
